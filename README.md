# BatteryIncluded Integrations

Source of [batteryincluded.eiling.io](https://batteryincluded.eiling.io): an introduction to
[BatteryIncluded](https://batteryincluded.ai) and all ways to integrate it – Shopware 6, Sylius, Symfony, PHP SDK and
the API.

The site is built by GitHub Pages with Jekyll and [Just the Docs](https://just-the-docs.com) from the `docs` folder.
