# API & data feed
{: .no_toc }

BatteryIncluded is integrated through a data feed and API calls, so it works with every shop system, language and
headless architecture – also where no plugin or SDK exists.

[API reference on Postman](https://www.postman.com/batteryincluded/core/overview){: .btn .btn-primary }

## What you build

1. **Export** – send your products and content as documents to your collection and keep them in sync on changes.
2. **Search** – call the browse endpoint for results and facets and the suggest endpoint for search-as-you-type.
3. **Recommendations** – fetch product, cart and preset recommendations for your templates.

The guides of the [PHP SDK](https://sdk.batteryincluded.eiling.io) describe the document schema, translations,
availability and all search parameters in detail – useful in any language.
