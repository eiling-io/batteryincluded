# BatteryIncluded Integrations

[BatteryIncluded](https://batteryincluded.ai) is AI infrastructure for e-commerce, made in Germany: a hybrid LLM search
that understands what your customers mean, merchandising your team steers without IT tickets and product
recommendations without user tracking – fully cookieless and GDPR compliant.

This site introduces BatteryIncluded and shows every way to bring it into your shop, from a ready-made plugin to the
plain PHP SDK.

[What is BatteryIncluded?](batteryincluded){: .btn .btn-primary .mr-2 }
[Choose your integration](integrations/){: .btn }

## Integrations

| Your shop | Integration | Effort |
|---|---|---|
| **Shopware 6** | [Shopware 6 plugin](integrations/shopware) by BatteryIncluded | Install and configure |
| **Sylius 2** | [Sylius Plugin](integrations/sylius) – search page, suggestions, category pages, recommendations | Install and configure |
| **Symfony** | [Symfony Bundle](integrations/symfony) – export, sync, search, Doctrine, Messenger, profiler | Build your templates |
| **Any PHP application** | [PHP SDK](integrations/php-sdk) – typed client for sync, search, suggestions, recommendations | Build your integration |
| **Everything else** | [API & data feed](integrations/api) – REST API, any language, any platform | Build your integration |

The Sylius Plugin, the Symfony Bundle and the PHP SDK are open source and build on each other, see
[how they fit together](integrations/#how-the-php-packages-fit-together).

{: .note }
> **Need a hand?** I help with every BatteryIncluded integration – Shopware, Sylius, Symfony, plain PHP or a custom
> platform: setup, data export, templates, tuning in the portal. [More about getting help](support).
